PFrank, short for Peter's Flexible RenAmiNg Kit, is a powerful automation tool designed to streamline the process of renaming files in bulk. - **Predefined Commands** — Choose from a variety of predefined actions such as adding prefixes, suffixes, or removing specific characters from file names.
- **Date Insertion** — Automatically include the current date in file names, helping you keep track of when files were created or modified.
